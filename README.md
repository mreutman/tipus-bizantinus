# Tipus Bizantinus

This is a modified version of the `GFS Artemisia` typeface designed to be used
with my own peculiar Latin orthography system. Being focused exclusivly on this,
the character set has been reduced to only that which is meaningful for my work.
I doubt anyone else but me will be interested in using this, but maybe it will
inspire someone else.

## Extending

I only really have experince with FontForge, so I assume if anyone wants to
extend this, you would also want to use FontForge as well, but there may be
similar tools that could used instead.

Outside of FontForge, no other software is required.
